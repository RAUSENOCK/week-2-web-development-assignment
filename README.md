# Budget Tracker

## Project Description

The Budget Tracker is a simple web application built using HTML and CSS. It helps users understand how to record, organize, and track their daily expenses.

This project is an improvement of the Budget Tracker created in Week 1. It includes an expense table, an expense form, a category dropdown, a logo, a budgeting video, and instructions for using the tracker.

## Features

- **Expense Table:** Displays sample expenses with their names, amounts, categories, and dates.
- **Add Expense Form:** Contains input fields for entering expense details.
- **Category Dropdown:** Provides five categories: Food, Transport, Rent, Entertainment, and Other.
- **Logo:** Displays an image near the main heading.
- **Budgeting Video:** Embeds a YouTube video about budgeting.
- **Instructions:** Uses HTML `<details>` and `<summary>` elements to show and hide instructions.
- **Table Styling:** Includes borders, alternating row colors, and hover effects.
- **Responsive Design:** Uses CSS to improve the layout on smaller screens.

## How to Run the Project

1. Open Visual Studio Code.
2. Open your existing Budget Tracker project folder.
3. Make sure `index.html`, `style.css`, and `README.md` are in the project folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code.
6. Explore the expense table, form, instructions, and budgeting video.

## How to Use the Tracker

1. Enter the name of an expense.
2. Enter the amount spent.
3. Select a category from the dropdown.
4. Choose the date of the expense.
5. Review the sample expenses in the table.

**Note:** The Add Expense button does not add new expenses yet. JavaScript functionality will be added in a future week.
